# Computer Science 정리 목차

> [!summary]
> Computer Science 폴더는 자료구조를 어떤 방식으로 표현하고, 어떤 기준으로 선택하는지 정리하는 곳이다.
> C++ STL 컨테이너와 연결해서 보면 실제 코드에서 어떤 구조를 써야 하는지 판단하기 쉽다.
