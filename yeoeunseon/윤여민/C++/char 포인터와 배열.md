# `char*`, `char**`, 배열

> [!summary]
> `char*`, `char**`, 배열은 한 번에 외우려고 하면 섞이기 쉽다.
> 이 페이지는 포인터와 배열 관련 문서로 들어가는 입구다.

## 문서 위치

| 주제 | 이동할 페이지 |
| --- | --- |
| `char*`, `char**`, `const char*`, `argv` | [[char 포인터]] |
| 배열, C 문자열, 2차원 배열, `T[R][C]`와 `T**` 차이 | [[배열과 C 문자열]] |

---

## 구분 기준

| 표현 | 먼저 떠올릴 것 |
| --- | --- |
| `char*` | `char` 하나를 가리키는 포인터 |
| `char**` | `char*`를 가리키는 포인터 |
| `char[]` | 문자들이 연속된 배열 |
| C 문자열 | 끝에 `'\0'`이 있는 `char` 배열 또는 그 시작 주소 |
| `T[R][C]` | `T[C]` 배열이 `R`개 있는 진짜 2차원 배열 |

---

## 읽는 순서

```text
배열과 C 문자열
→ char*와 char**
→ argv와 문자열 목록
```

`char*`를 먼저 보면 문자열처럼 느껴져서 헷갈릴 수 있다.

배열과 C 문자열의 끝 표시 `'\0'`을 먼저 잡고, 그다음 `char*`가 그 메모리를 가리킨다고 보는 편이 안정적이다.
